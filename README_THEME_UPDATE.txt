RUN
1. Extract this ZIP.
2. Open start_game.bat (or run `npm start` if Node.js is installed).
3. Open the localhost URL printed by the server in Chrome or Edge.
4. Allow camera access and press START CAMERA.

CHECKS
`npm run check` and `npm test` pass, including browserless game progression and gesture/camera logic smoke tests. Real webcam hardware and lighting must be tested on the target computer.
